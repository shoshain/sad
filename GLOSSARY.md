# Glossary

- **Constitution.** Project-level governance file (`.sad/memory/constitution.md`). Loaded into every phase. Defines unbreakable rules. Borrowed from GitHub Spec Kit.
- **Tier.** One of three stakeholder audience categories: non-technical, semi-technical, technical. Novel to SAD.
- **Walkthrough.** Tier-specific artifact summarizing a feature for one stakeholder audience.
- **Reconcile / Reconciliation.** The numbered phase that closes the spec-code bidirectional loop. Produces `reconciliation.md`.
- **Impact Forecast.** Pre-plan predictive analysis of downstream effects. Adapted from Ramarajan.
- **Reviewer Fleet.** Parallel sub-agents producing structured review reports. Borrowed from Compound Engineering with `architectural-conformance` added.
- **Compound (verb).** The act of writing a Decision + Lesson record from a completed feature. Borrowed from Every Inc.
- **EARS.** Easy Approach to Requirements Syntax. `WHEN <trigger> THEN the system SHALL <response>`. From AWS Kiro.
- **Bolt.** Short execution loop (hours to days), borrowed from AWS AI-DLC. Replaces sprint.
- **Guide / Sensor.** Feed-forward versus feed-back harness components. From Martin Fowler.
- **Spec Drift.** Divergence between spec and implementation. The condition `spec-drift-detector` is built to find.
- **Story File.** Self-contained context capsule for a single task; preserves context across handoffs. Borrowed from BMAD-METHOD.
