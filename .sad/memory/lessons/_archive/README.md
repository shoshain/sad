# Archived lessons

Lessons moved here by `/sad-compound-refresh` are superseded by code removal, a constitution change, or a product pivot.

Each archived file SHOULD include a tombstone header explaining **why** it was archived and **what** replaced it (a newer lesson, a constitution amendment, or "no replacement; this concern is gone").

Convention:

```markdown
---
archived_on: 2026-05-08
superseded_by: .sad/memory/lessons/2026-05-08-new-greeting-policy.md
reason: greeting feature replaced by full profile editor
---

# (original lesson content preserved below)
```

History is preserved — `/sad-compound-refresh` does **not** delete; it moves and annotates.
