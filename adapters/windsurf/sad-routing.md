# SAD routing

This project follows the **Stakeholder-Anchored Development** methodology. Read `AGENTS.md` at the repo root for the declared-precedence block, then read `.sad/memory/constitution.md` for project policy.

## Rule precedence

1. `.sad/memory/constitution.md` (immutable project policy)
2. `AGENTS.md` (operational entry point)
3. `.windsurf/rules/` (this file — tool-mechanical only)
4. user-level rules
5. assistant defaults

If you detect a conflict, surface it.

## On every session, read

1. `AGENTS.md`
2. `CHEATSHEET.md`
3. `.sad/memory/constitution.md`
4. `.sad/rules/core/README.md`
5. `.sad/state/sad-state.md`

## /sad-* commands

Canonical prompts at `commands/sad-<command>.md`. Follow them verbatim.

## Approval is human-only

Even at Level 0, AI never ticks a walkthrough approval checkbox.
